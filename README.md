# Wierzba13 Blog

Repozytorium mojego bloga technologicznego - strona jest generowana statycznie i hostowana bezpośrednio na platformie GitHub Pages.

🔗 **[Odwiedź bloga: wierzba13.github.io](https://wierzba13.github.io/)**

## O projekcie
To miejsce, w którym dokumentuję swoją inżynieryjną ścieżkę, publikuję wpisy o programowaniu (m.in. Java, Spring Boot, React) i dzielę się technicznymi rozwiązaniami. Wszystkie artykuły pisane są w formacie Markdown.

## Zastosowane technologie
* **Jekyll** – generator stron statycznych
* **GitHub Pages** – wdrażanie i hosting
* **Git** – kontrola wersji

## Motyw
Blog korzysta z motywu **[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy)**, którego autorem jest [Cotes Chung](https://github.com/cotes2020).
